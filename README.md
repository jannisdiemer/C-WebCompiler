# C++ Compiler in PHP

A C++ compiler written in PHP as a learning and hobby project.

The goal of this project is to implement a subset of C++ step by step, including lexical analysis, parsing, semantic analysis and code generation.

## Features

Currently planned:

- Lexer / Tokenizer
- Parser
- Abstract Syntax Tree (AST)
- Semantic analysis
- Type checking
- Intermediate Representation (IR)
- Code generation

Supported C++ features will be added incrementally.

## Current Language Support

Planned first version:

- `int`
- integer literals
- variable declarations
- assignments
- arithmetic operators
  - `+`
  - `-`
  - `*`
  - `/`
- functions
- `return`
- basic expressions
